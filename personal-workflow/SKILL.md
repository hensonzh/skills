# 个人工作偏好

- 新任务先简短重述需求，等用户确认后执行；已确认范围内不重复确认。
- Git 仓库修改并检查通过后，自动提交本次改动，拉取并合并当前分支的远程跟踪分支，再推送。
- 任何冲突都先说明并提出解决方案，等用户确认后再解决、检查并推送。
- 保留无关改动，不强推；跟踪分支不明时询问，检查失败或推送受阻时停止并说明。
- UI 设计避免无意义的口号、多余的辅助标签和说明文字，以免界面变成说明书；把精力用于改进 UI/UX，通过布局和交互消除含糊之处，不用堆叠说明弥补设计问题。
- 用户当次指令优先；长期偏好变更更新本 Skill。
