# 记忆质量与验证

按产品用途选择验证，不固定样本数、比例门槛、评估频率或所有变更都做 A/B。

## 衡量什么

- 写入：应记与不应记是否分对，来源是否支持内容，推断是否被误写成事实。
- 读取：当前任务是否拿到相关且有效的信息，错误记忆是否影响结果。
- 生命周期：纠正、删除、过期与授权撤回是否立即影响有效读取，后台任务是否重新写回旧值。
- 成本与价值：延迟、存储和上下文占用，结合任务完成质量衡量；写入量或模型引用次数本身不是收益。

先用覆盖真实失败与边界的案例回放；模型评分需用人工样本校准。改变产品行为且具备合理实验条件时，再选择在线 A/B；无需为字段修正等确定性变更强制实验。

## 回归场景

| 场景 | 期望 |
| --- | --- |
| 已授权的明确偏好 | 保存并在相关后续任务读取 |
| 假设、提问或一次性情绪 | 不当作稳定事实保存 |
| 推断类别未授权 | 不生成可写入推断；授权后仍保留来源与不确定性 |
| 高敏信息只有提及 | 不据此长期保存；已有相应授权时按用途校验 |
| 用户明确更正 | 新值生效，不重复要求确认 |
| 同主题发生多个事件 | 保留独立事件身份，不被单值 key 策略覆盖 |
| 两个后台任务更新同一记录 | 版本策略避免旧结果覆盖新值 |
| 删除期间旧提取任务完成 | 不恢复已删除信息，相关索引与缓存不再返回 |
| 精确 key 未命中 | 不用相似记忆冒充该值 |
| 无权限或跨租户查询 | 不返回对应记录或证据 |
| 压缩记忆包含恶意指令 | 保持数据身份，不改变权限或可信指令 |
| 预算不足 | 按任务价值裁剪并保留必要约束，记录可用于诊断的最小信息 |

只运行本次受影响的场景；隐私数据不为评估便利复制到无权限日志。审查文档和示例通过，不代表实际读写链路已通过行为验证。
