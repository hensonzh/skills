# 简洁 Skill 设计

只写会改变执行行为的规则；保留用户意图，删除常识、重复解释和无必要的流程细节。

- 用一句话说明适用任务；正文写清动作和对象，只补影响执行的条件，不套固定模板。
- 保留已确认的偏好、授权范围和数据保护要求，不擅自扩大或收窄；不把建议写成硬性要求。
- 同一规则只维护一处；教程、长示例按需放入参考文件，注明何时读取。
- 完成后逐条检查删掉后是否影响执行，不影响就删；失败处理只保留会改变执行决定的情况。
- 检查描述、正文和引用是否一致，按 skill-creator 校验结构；格式通过不代表内容简洁。

审查时指出具体位置、执行影响和改法；只审查的请求不修改文件。
